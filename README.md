# nfl-award-predictor
playing around with nfl stats to predict nfl awards such as: mvp, opoty, etc

## Setup
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run
```bash
python test.py
```

Add a package: `pip install <pkg>`, then add it to `requirements.txt`.
Leave the venv: `deactivate`
